## Setup

Use Python 3.9 or newer. Run these commands from the repository folder.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

All datasets are generated by the scripts. No external data files are needed.

## Run the experiments

```bash
MPLBACKEND=Agg python assignment3_template.py --task plot
python assignment3_template.py --task svm
MPLBACKEND=Agg python kmeans_template.py --seed 0 --max-iterations 100
python noisy_classification_template.py --repeats 20 --seed 0
```

The plotting commands save images without opening a graphical window.

| Script | Output |
| --- | --- |
| `assignment3_template.py` | `svm_data.png` and terminal output for the support vectors, weights, bias, and margin |
| `kmeans_template.py` | Five plots in `results/kmeans/` for k values 2, 3, 4, 6, and 10 |
| `noisy_classification_template.py` | Twenty trial results in `results/noise_comparison.csv` and mean accuracies in the terminal |
